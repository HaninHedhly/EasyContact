# EasyContact - Contact Management Application - Java Swing & SQLite

## 🎯 Objective
Build a desktop contact management app with a stylish, user-friendly design, supporting full CRUD operations and persistent storage using SQLite.

## 🛠️ Approach
- Developed a multi-window Java Swing application (login, main menu, add/view/edit/delete contacts).  
- Styled the UI with a girly aesthetic (pink, violet, beige, rounded buttons).  
- Integrated SQLite for secure and reliable data storage.  
- Used event-driven programming to handle user interactions.  
- Applied object-oriented design with `Contact` and `ContactManager` classes.

## 💻 Tech Stack
- **Java (Swing)** – GUI and business logic  
- **SQLite** – data persistence  
- **JDBC** – database connectivity  
- **Eclipse IDE** – development environment  
- **GitHub** – version control & project hosting  

## 🌟 Project Highlights
- Full CRUD functionality for managing contacts.  
- Login authentication to secure access.  
- Database-backed persistence using SQLite instead of JSON.  
- Modular structure: separate windows for each action.  
- Aesthetic and personalized UI to enhance user experience.
